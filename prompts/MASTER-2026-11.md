1. When a track (or a pre-registration) is ready, push it and open its PR, end the phase report
   with "Ready for Claude review", **and** create the empty marker file
   `reports/reviews/queue/<track-id>.ready` on that branch.
2. Claude checks the repo about every 30 minutes, reviews, and writes
   `reports/reviews/<track-id>-review.md` **on `main`** with a verdict:
   - **APPROVED:** Claude merges the PR into `main`.
   - **APPROVED WITH FIXES / CHANGES REQUIRED:** apply the listed fixes on the same branch,
     push, and refresh the `.ready` marker.
3. Poll `main` (`git fetch origin main`) about every 15 minutes for your review files while you
   work on other tracks. Never wait idle if other tracks have work.
4. **Pre-registrations (G, K) always stop for review:** commit the registration and its SHA-256,
   mark `<track-id>-prereg.ready`, and read **no genuine data** until
   `reports/reviews/<track-id>-prereg-review.md` on `main` says APPROVED.
