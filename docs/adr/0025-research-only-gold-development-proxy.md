# ADR0025 — research-only gold development proxy

Proposed for pre-registration review,2026-11-03. This extends frozen F research
mechanics without changing XAUUSD's data-only role or any risk/cost configuration.
No genuine input is authorized before main's pre-registration approval.

Use a closed non-iterable proxy batch with explicit historical_research purpose.
Refuse paper/local simulation/Testnet/execution before input consumption. Keep
original XAUUSD input identity, map privately for XAUT plugins, label outputs, and
provide no runtime bar export. Only session_orb is added to XAUT's allowlist.
F engine/risk/statistics stay unchanged; reuse them after independent review.

Freeze low-range stop, fifteen-minute OR, two local timing anchors and independent
DST,54cells, past-only fixed coverage windows and5%missing cutoff before data.
C's unavailable VWAP is not replaced with invented volume. A keeps its existing
LIMIT semantics; stricture0.25%/2trades on XAUT remains. No2024input or validated
pass. Development can Reject/Promising/Insufficient only, then freeze price-free
training choices for a separately reviewed2024phase.

Alternatives rejected: turn XAU into an executable asset, share proxy bars with
paper, infer spreads from bid candles, synthesize volume, tune quality after gaps,
use current-clock fixed UTC offsets, or label development as validation.
See the registration, research note and phase report for formulas and consequences.

Bound historical replay returns labelled results only, never an unscoped engine.
An explicit counterfactual prior-bid capacity input exercises the frozen engine
without inventing provider/feature volume; its quantity bound does not supersede
current funded cash/exposure/risk checks. Claude reviews this exact assumption
pre-data. Known Reject criteria precede unknown evidence; Promising freezes need
a registered nonnull cell. Copied immutable inputs preserve whole-batch preflight.
