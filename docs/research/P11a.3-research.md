# P11a.3 research — Twelve Data Basic

Official documentation reviewed 2026-10-23. This phase uses a small deterministic REST
client and existing storage. No paid service, broker orders or agent-owned collector.
Endpoint availability and source-data qualification are separate from execution readiness.

| Question / option | Finding / decision |
|---|---|
| /price | Returns price alone; insufficient source-time evidence. Do not use. |
| /exchange_rate | Returns exact symbol, rate and Unix timestamp; request timezone=UTC. Genuine point probes were ~114-116s old and rejected by the 90s point freshness bound. Keep optional; do not reinterpret its timestamp as a bar close. |
| /time_series | Intraday OHLC, bar-open datetime, metadata; request timezone=UTC explicitly. Record original exchange timezone separately. Use M1; no invented volume. |
| /api_usage | Actual minute/day limits and usage confirmed against the official endpoint. Inspect before market requests; require Basic rather than assuming an account tier. |
| SDK vs httpx | Existing pinned httpx supplies a small GET-only host/path/parameter allowlist; no new SDK or order capability needed. |
| Clock handling | Validate documented UTC epoch/bar-open representation and receipt clock against TLS HTTP dates and independent UTC references. Minute cadence is freshness, not a guessed offset. Original broker clock profiles stay unchanged. |
| Entitlement | Check EUR/USD and XAU/USD separately against this key. Gold's Forex v2 listing does not establish Basic access. |
| Limits | Persist account-scoped conservative reservations and server usage in SQLite; cache within cadence, enforce minute/day budgets, obey Retry-After, no automatic retries/upgrades. |
| Storage / display | Personal noncommercial internal development only. Raw data stays ignored. Basic pricing says internal non-display; prices hidden in dashboard pending explicit display rights. No permanent archive, redistribution or commercial usage rights inferred. |

Sources (accessed 2026-10-23):

- [REST schemas and authentication](https://twelvedata.com/docs): recommended Authorization header, fixed endpoints, UTC request parameters.
- [Official API](https://twelvedata.com/docs): the authenticated official /api_usage response confirmed current_usage, plan_limit, daily_usage, plan_daily_limit and plan_category; no third-party schema is an implementation authority.
- [Forex v2](https://support.twelvedata.com/en/articles/12520817-forex-api-v2): composite minute midpoint feed and precious metals coverage.
- [Price methodology](https://support.twelvedata.com/en/articles/11850499-understanding-price-deviations-in-commodities-and-forex-data): midpoint is not broker-executable.
- [Credits](https://support.twelvedata.com/en/articles/5615854-credits): minute resets, UTC midnight daily reset, credit headers.
- [Timezones](https://support.twelvedata.com/en/articles/5745849-timezones): FX default differs from UTC; explicit override required.
- [Historical prices](https://support.twelvedata.com/en/articles/5656039-how-to-get-historical-prices): symbol-specific depth; initial downloads stay backfill.
- [Pricing](https://twelvedata.com/pricing): Basic free, 8/minute, 800/day, internal non-display; commodities depend on tier.
- [Terms](https://twelvedata.com/terms): tier-bound internal processing/storage, free noncommercial use, no assumed redistribution or indefinite caching.
- [Personal usage](https://support.twelvedata.com/en/articles/5332349-commercial-and-personal-usage): development/research distinction; plan and application-specific rights remain relevant.

Measured results: Basic returned EUR/USD Physical Currency and XAU/USD Precious Metal M1 data.
Forex metadata supplied currency_base/currency_quote/type but omitted exchange_timezone;
the adapter preserves that absence and the explicit UTC request. Four newly observed completed
M1 bars per instrument qualified during 18:13:23-18:18:46 UTC. Completion-to-receipt delay was
41.879-102.683s, so candle freshness is evaluated from the bar end, separately from point prices.
Both /exchange_rate values matched their latest returned candle closes in the initial probe;
that measurement does not establish the rate timestamp's undocumented bar semantics.

Remaining unknowns: provider finality/revisions, long-running reliability, historical coverage,
long-term retention allowance and personal dashboard display rights. Numeric market data stays
out of Git. Full outcomes and source code fingerprint are in the phase report.
