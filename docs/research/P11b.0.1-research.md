# P11b.0.1 research and frozen protocol

Sources checked2026-10-24 UTC before implementation/scoring. This is a deterministic mechanics
study on owned synthetic data, not an empirical trading backtest or investment recommendation.
No market-data requests, reserved historical evaluation, cost/fill inference or model training.

| Question / option | Frozen decision and reason |
|---|---|
| EMA seed and recursion | First-close seed; alpha2/(n+1), recursive update, periods12/26. Reuse shared FeatureEngine; no parallel signal-specific indicator implementation. |
| Warm-up | 52 contiguous M5 observations for EMA and channel, at least26/21 respectively configurable upward/downward within validated limits; ATR14 must exist. Reset after gaps. |
| EMA transitions | First eligible non-neutral regime after warm-up, then changes in sign; neutral when separation<0.1ATR. One signal per regime transition; filtered transitions are consumed. |
| Breakout | Close strictly beyond prior20 highs/lows plus0.1ATR; exclude current candle. Default one completed close; optional1-3 confirmations. Same-side active breakout suppressed until inside/opposite regime. |
| Volatility | ATR14/close range0..0.02 and current true-range/priorATR<=4. No volume, book, sessions or costs inferred. Defaults fixed before scenarios, not optimized. |
| Future labels | Horizons1/3/6 full M5 intervals beginning at ceil(decision availability to next M5 opening). Zero-bps flat threshold. Same-source contiguous committed observations required. |
| Dependence / baselines | WAIT excluded; report all and non-overlapping outcome counts separately per symbol/strategy/horizon. Always-WAIT abstention and always-UP/previous-move comparisons use identical outcome windows. Never pool overlapping horizons as independent trials. |
| Existing studies | Default model remains legacy-compatible; new YAML explicitly enables two reference hypotheses and pins new versions/config. New output namespace; no old journal migration/rewrite. |
| Rights | No support response exists. Proposal validation must require documentary kind/hash, reviewer, exact account/symbol scope, expiry and retention; request-pending evidence cannot approve use. No actual approvals written. |
