Inspected 2026-10-27 UTC, using public official documentation only. No historical
dataset, account, API key, subscription or provider connection was used. Rankings
below are engineering judgments conditional on independent license review, not
certifications or authorization to download. No genuine dataset is admitted.

HistData explicitly documents fixed EST without daylight-saving adjustment; do not
use America/New_York for those stamps. Its data lacks aggregated volume and has
documented gap diagnostics without a completeness warranty. A source-specific
conversion must preserve fixed UTC−5 provenance, original bytes and documented
bar availability. [Official FAQ](https://www.histdata.com/f-a-q/),
[formats](https://www.histdata.com/download-free-forex-data/) and
[stated backtesting purpose](https://www.histdata.com/about-us/).

Dukascopy exposes an [official historical exporter](https://www.dukascopy.com/swiss/english/marketwatch/historical/)
and [historical API documentation](https://www.dukascopy.com/wiki/en/development/strategy-api/historical-data/).
[IHistory](https://www.dukascopy.com/swiss/docs/interfaces/IHistory.htm) describes
instrument, period, side and time selection; this does not itself grant retention
rights or prove the exact local file's timezone. The
[website terms](https://www.dukascopy.com/swiss/english/legal-pages/terms-of-use/)
permit limited personal downloads but contain material database/derivation and
automation restrictions. That makes the proposed persistent analytical database
NO-GO without applicable specific permission. A separate XML-feed license cannot
be applied indiscriminately to historical BI5/CSV data.

Twelve Data's [forex product page](https://twelvedata.com/forex) describes currency/
precious-metal coverage and JSON/CSV history. Its general historical-depth claim
must not be substituted for exact instrument/interval entitlements. The
[personal/commercial guidance](https://support.twelvedata.com/en/articles/5332349-commercial-and-personal-usage)
describes permitted internal/educational uses for named individual plans, with
plan-dependent derived-data and redistribution conditions; it does not settle all
Basic-plan archive rights. [Official API documentation](https://twelvedata.com/docs)
is the schema reference for any future authorized export (the large documentation
page could not be fetched fully during this review). No availability or permission
is inferred from previously configured keys or prior forward-feed results.

For all candidates: no fixed multi-year depth or completeness is asserted without
actual file qualification; no country restriction is inferred absent a reviewed
applicable agreement. Bid/ask history from one broker does not establish another
broker's contract, fees, execution depth, funding, account eligibility or fills.
No source is currently approved for this application's persistent research.

## Design references and choices

Existing project components remain authoritative: FeatureEngine, EMA/channel
plugins, completed-bar aggregation, direction/future-window evaluation and
DecisionLedger. The local orchestrator adds rights/provenance and frozen-run
boundaries, not another strategy/risk framework. Use bounded local shards rather
than a multi-year tick load. Polars documents streaming
[collect_batches](https://docs.pola.rs/api/python/stable/reference/lazyframe/api/polars.LazyFrame.collect_batches.html);
installed pinned Polars 2.0 supports the selected 1,000-row batches.

Non-overlap reduces duplicate outcome exposure but cannot establish independent
financial observations. The [NIST confidence-interval reference](https://www.itl.nist.gov/div898/handbook/prc/section2/prc241.htm)
informs the descriptive Wilson interval; minimum count 30 is a frozen reporting
threshold, not a mathematical guarantee of significance or profitable skill.
Synthetic examples receive no inferential interval. A dependence-aware inferential
design, multiple-testing plan and genuine licensed data belong in a reviewed
future research phase, without changing the frozen MVP to improve its results.

Next recommended P11c.1 scope: qualify one small rights-approved EURUSD shard first,
prove timestamps and original acquisition/retention, run the frozen protocol,
report insufficient evidence honestly, then separately admit XAUUSD if its own
rights/units/coverage pass. Keep broker OAuth, genuine paper execution and AI/ML
promotion outside that phase unless separately authorized.
