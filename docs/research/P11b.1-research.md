## Protocol sources and implications

- [Official overview](https://help.ctrader.com/open-api/) — JSON does not require the SDK; request limits.
- [Account authentication](https://help.ctrader.com/open-api/account-authentication/) — accounts versus trading OAuth scopes. `permissionScope` is returned by account-list response, not inferred from a locally configured string.
- [Messages](https://help.ctrader.com/open-api/messages/) — auth, identity, assets, symbols, subscription and disconnect/token-invalidated messages.
- [Model definitions](https://help.ctrader.com/open-api/model-messages/) — `SCOPE_VIEW=0`, volume cents, precise cost types, server symbol IDs, schedules and holidays. A numeric zero is a valid view scope, not missing evidence.
- [Symbol data](https://help.ctrader.com/open-api/symbol-data/) — optional sides and timestamp subscription. Missing sides wait for a separately timed fresh counterpart; never manufacture a spread.
- [Demo/JSON endpoints](https://help.ctrader.com/open-api/proxies-endpoints/) — demo.ctraderapi.com:5036, TLS; no configurable URL or live host.
- [Connection](https://help.ctrader.com/open-api/connection/) and [JSON envelopes](https://help.ctrader.com/open-api/sending-receiving-json/) — heartbeat, message queue, client correlation ID and integer payload types.
- [Python SDK](https://help.ctrader.com/open-api/python-SDK/python-sdk-index/) — official Twisted alternative evaluated, not installed. [SDK source pin](https://github.com/spotware/OpenApiPy/tree/e944996e6fe9436b8b4a1b668da4ac41a826bb85), last default-branch commit 2024-08-07, MIT. No upstream source copied.
- [Official protocol pin](https://github.com/spotware/openapi-proto-messages/tree/3fd8bddfbe0cfc2ecfda079623dc4e498af11e66), 2025-11-13, MIT — read schemas to verify message IDs/types. No execution message constructors imported.
- [API terms](https://help.ctrader.com/open-api/terms-of-use/) — API offered without a fee under stated conditions; registration/use entails terms. Owner alone creates/accounts/accepts agreements. Broker data rights still need affirmative evidence.
- [cTrader demo accounts](https://help.ctrader.com/ctrader/trading-accounts/) — general virtual-funds behavior; no Pakistan/account entitlement inference.
- [OANDA authentication](https://developer.oanda.com/rest-live-v20/authentication/) and [pricing](https://developer.oanda.com/rest-live-v20/pricing-ep/) — token breadth, account-specific prices and sampled stream.
- [OANDA regional demo process](https://help.oanda.com/uk/en/faqs/open-demo-account.htm) — country/entity choices; no owner account creation or regional approval established.

Accessed all sources 2026-10-25 UTC. No provider was contacted for permission; no financial advice or broker endorsement is implied by protocol comparison. Storage/display/legal/Shariah approval remains independently unverified. Source timestamp unit and fresh independent UTC checks must pass for a real account; fixture decoding is not genuine clock qualification.
