# P09 phase report — append-only decision ledger and AI arena

P09 provides immutable local AI evidence and an offline multi-provider review arena. The complete
mock workflow runs without keys or market data and can only veto or reduce an existing setup. Paid
providers are implemented but policy-disabled until a human supplies current nonzero prices.

## Delivered components

| Requirement | Implementation and constraint |
|---|---|
| Ledger | Local SQLite WAL; decisions, model calls, outcomes, hypotheses, and interventions; required versions and row hashes; triggers reject update/delete. |
| Resolution/export | Outcomes append against prior decision IDs. All tables export atomically to Zstd Parquet with row count, byte count, checksum, time, and code version. |
| Providers | Deterministic mock; constrained local Ollama; generic OpenAI-compatible; native Anthropic; non-calling Jev stub. Missing keys disable adapters. |
| Snapshot | Frozen feature-only schema rejects identifier, date/time, and raw-price field tokens before hashing/calling. |
| Arena | Independent answers, one anonymized cross-review, fixed-schema hypotheses, TTL response cache, and immutable attempt logging. |
| Authority | Valid multipliers are bounded `[0,1]`; all valid outputs combine by minimum; skip/veto is zero. Invalid/unavailable output has no power. |
| Budget | Human YAML, global `$20/month` ceiling, provider day/month/max-call caps, actual token accounting, paid providers disabled until nonzero pricing is configured. |
| Scoring | Brier, clipped log loss, reliability bins, multiplicative/Hedge weights, identical-answer herding flag, and pairwise error correlation. |

## Offline acceptance

`reports/arena/P09.json` records one mock independent answer, one cross-review, one queued
hypothesis, five Gold table exports, a 0.75 reduction multiplier, zero paid calls, and zero final-set
reads. This proves mechanics only; it is not evidence of trading value.

## Limitations

- No AI model has demonstrated forecast skill, veto value, hypothesis hit rate, or net benefit.
  P07/P08 eligible-history blockers make these empirical metrics NOT EVALUABLE.
- No live Ollama instance or paid API was called. Adapter contracts are verified with local HTTP
  fixtures; provider-side changes require an explicitly enabled, budgeted live test later.
- Pricing is intentionally not guessed. Paid policies cannot be enabled while both token prices are
  zero, and current model prices remain a human maintenance responsibility.
- SQLite WAL is local-host storage; do not place the live database on a network share.
