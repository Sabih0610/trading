has no direct native MT5 entries. Newly installed project MCP tools require a **Codex restart**;
the current chat catalog is not claimed to have hot-reloaded. Protocol verification used the
actual installed proxy directly.

**Native application limitation:** MT5 reports MCP trading permission enabled and expert trading
disabled. The proxy provides a separate enforced read boundary; it cannot change the native
setting. Disable native AI/MCP Trading and dangerous shell operations in MT5 settings. Never attach
Codex directly to the raw endpoint. A token holder outside this proxy still has the native surface.

## Python adapter and genuine findings

The official Windows SDK is optional and exactly pinned at **MetaTrader5 5.0.6231**. The reader
captures only approved data callables, rejects account-login arguments and refuses to launch a
terminal implicitly. It attaches only to an already-running explicit executable. Demo mode,
account/server and terminal path are checked before/after reads; real/contest/unknown/mismatched
identities abort. Transient disconnects retry the same pins with bounded exponential backoff.

Exact aliases require verified base/quote facts; the adapter never selects/unhides a symbol.
Metadata includes contract/tick/point/digits/volume grid, tick value, currency/conversion needs,
trade status, spread and observation source/time. Missing facts do not receive invented defaults.
The existing ContractSpec requires costs/pip/conversion/session assumptions that a price API does
not establish; its adapter method deliberately refuses sizing. External eligibility remains false.

[The genuine diagnostic record](../mt5/P11a-connectivity.json) shows:

- Verified MetaQuotes-Demo identity, USD and terminal Build 6281 via Python and native MCP.
- EURUSD metadata available, including 100,000 contract size and 0.00001 tick size from Python.
  Native MCP reported zero tick size/value in the inspected Market Watch response; those zeros
  are not sizing facts. Its JSON time representation lacks the Python tick's millisecond field.
- EURUSD source epoch interpreted under the documented UTC convention is approximately **10,800
  seconds ahead of receipt UTC**. The native server/quote textual clock shows the same mismatch.
  Quotes are refused, archived only as raw observations, and not exposed as forward data. No
  timezone shift, machine-clock edit or manufactured price is applied.
- XAUUSD is a genuine XAU/USD contract but hidden from Market Watch and has no usable quote in
  this run. GOLD on this broker is Barrick Gold stock, not a valid alias. No visibility mutation.
- No genuine prospective candle, strategy return, model accuracy or continuous-run claim is made.

The native-vs-Python comparison, official sources and access date are in
[research](../../docs/research/P11a-research.md). MCP is useful for occasional development,
discovery and verification; the deterministic SDK collector owns data polling. Neither interface
has measured 24/7 reliability here; both still depend on a running, connected terminal.

## Persistence, provenance and dashboard

The collector polls at five seconds, requests bounded candle tails no more often than once per
minute, and optionally retrieves a bounded historical tick window. Supported bars are
M1/M5/M15/H1/H4; unfinished/future candles are refused. SDK None/error conditions are explicit.
No future timestamp is normalized by guessing a broker offset.

Raw observations are append-only under `data/bronze/mt5_feed/`; validated, UTC, deduplicated
records live under the parallel Silver namespace. Reuses atomic/fsync writes, SHA-256 helpers,
BronzeManifest, MarketQuote validation and the existing M1 cleaner/session flags. Tick activity
is not global forex volume; non-candle trade-volume semantics remain explicitly unverified.

Each batch commits files/manifests first, then a single SQLite transaction for dedup IDs,
watermarks and checkpoint. Partial writes remain quarantined orphans; they do not advance state.
Restart verifies the last committed manifest/bytes, and the process lease prevents overlapping
CLI writers. Duplicates ignore receipt/evidence relabeling; gaps/out-of-order facts are recorded.
Storage/batch/tick-history limits are configured; capacity exhaustion stops instead of deleting
source history. Current quota scans and retention need scale measurement before long runs.

Historical research, backfill, forward observations and synthetic fixtures have explicit labels.
A new receipt timestamp cannot turn old ticks into forward observations. Forward quotes require
an immutable session start and bounded lag. Completed forward candles also require uninterrupted
interval coverage and timely receipt; gaps/restarts reset coverage. Sampled quotes do not become
reconstructed full-tick candles. Old historical ingestion does not scan the new namespace.

P10 now has a separate **Market Feed** view reading only small, checksum-verified, indexed exports.
Unique payloads and atomic pointers prevent mixed snapshots, even when the clock repeats. The
reader validates session/evidence/kind/coverage and never opens raw history. The old historical
account reader retains its 2025+ refusal. Feed prices never join synthetic account P&L. Stopped,
stale, delayed, unknown and unavailable states remain explicit; broker sessions are unknown
unless independently established. This is data monitoring, not an active trading bot.

has finished; only the read-only dashboard is left running on http://127.0.0.1:8501.

finite run; no persistent task was installed. Independence from Codex/LLMs is deliberate.

permission settings, separate hosted-service authentication and long-running supervision/retention
remain explicit limitations. No data repair or account/setting change is concealed. The short
smoke does not establish 24/7 reliability, eligible trading or empirical strategy performance.

[The P11b proposal](../../docs/P11b-proposal.md) recommends an independently supervised Python

reconciliation and restart/clock/storage tests followed by an explicitly scoped 24h soak. Native
MCP remains an inspection aid. No P11b implementation, EA, broker order or soak was started.
