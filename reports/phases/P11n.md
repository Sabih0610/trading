## Result and boundaries

Gold1d uses UTC midnight windows; Gold1w opens Monday00:00 UTC. Bars keep observed,
expected, observed-expected and unexpected source-minute counts. Completeness
requires at least95% expected coverage, an ended window entirely inside admitted
history, and no calendar conflict. Missing OHLC stays null. Expected-zero closed
windows are metadata rather than fabricated complete signal bars. Coverage/gap
knowledge is available only at the exclusive window end; missing expected-open
periods reset usable feature history, while closed empty periods do not.

The shared FeatureEngine has an explicit opt-in swing stream with bounded state.
Fixed SMA/EMA20/50/100/200 and slopes, Wilder ATR14, prior-bar Donchian20/55, sample
RV20 and strict three-left/three-later confirmed swings are recorded in manifests.
The native intraday calculation path is preserved. Weekly warm-ups can remain
null; no earlier or substitute price series is used to fill them.

New immutable outputs and separate pointers use only swing-v1. Source labels stay
HistData XAUUSD bid and Binance trade data, including PAXGUSDT as PAXG rather than
XAUT. Old source manifests and Silver hashes were reverified unchanged. The build
never writes old intraday Gold or replays F/G. Original current rights, evidence
and finite retention were admitted before and after derivation without renewal.

The approved compiled scope is BTCUSDT/ETHUSDT/SOLUSDT2020-10 through2024,
HistData XAUUSD2021–2023 only, and PAXGUSDT2023-12 through2024-12. No EUR, new
download,2020/2024 XAU,2025+ observation, sealed forward archive or P14 access was
added. Build completion metadata is in

## Causal API and limitations for P

`timestamp_utc` is window open; `bar_end_utc` is exclusive close. Complete price
and feature availability is `available_at`; ended-window metadata availability
is separately `coverage_available_at`, including missing-price barriers.
The O/P bridge must map missing expected-open null OHLC to HistoryGap, partial
observed incomplete bars to incomplete CompletedBar, and omit empty closed days.
It must carry N's confirmed_at or explicitly use the same fixed three-bar delay.

Year partitions use max(window-open year, first admitted source year). The initial
cross-year partial week stays in the first admitted-year output with its actual
open, actual first observed minute and incomplete flags, without earlier source
access. P must filter ended/available windows against its registered cutoff,
including late-December windows that close in the next year. Generation complete
means the immutable output was published, never that every contained bar is complete.

The private read-only day-bound1m accessor admits current source rights/checksums
and returns immutable points only for that completed day; other-day requests refuse
before IO. It is for engine fill ordering, never a signal input. Minute OHLC does
not resolve stop/target ordering within the same minute. P must pre-register that
ambiguity convention and sensitivity before genuine evaluation. P remains gated
by its independent pre-registration approval on main; this phase ran no strategy,
chart, order, paper session or risk change.
