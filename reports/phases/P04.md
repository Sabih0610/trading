P04 is in progress. It will produce incremental UTC-aligned Silver datasets, anomaly flags, resampled bars, cross-market alignments, and data-quality reports without lookahead.

## Built

- Strict adapters normalize Binance spot klines and paired Dukascopy BID/ASK candles into one UTC
  1m schema, rejecting missing sides, nulls, non-finite values, nonpositive prices, and inconsistent
  OHLC bounds.
- Cleaning deterministically sorts and deduplicates, preserves and counts missing minutes, flags
  rather than removes extreme past-only returns, and applies Asia/London/New York/DST/weekend tags.
- Left-closed `5m`, `15m`, `1h`, `4h`, and `1d` aggregation emits only windows whose right edge is
  at or before the build cutoff, with source-row completeness exposed.
- Each output manifest binds the exact Bronze checksum to the output checksum and transformation
  version. Atomic replacement prevents partial targets; unchanged lineage is skipped.
- Calendar schedules and news headlines share `timestamp_utc`/`known_at` semantics and a common
  578-row timeline. Calendar release values remain in Bronze until observation times are available.
- Seven XAUT/XAU files use exact-minute joins. The two weekend sample days have 1,440 null basis
  rows each; no stale XAU price is carried forward.
- The verified sample contains 514 Silver Parquet files, 167,056 rows, and 6.9 MB. The 84 market
  partitions contain 120,960 1m rows, 13 flagged spikes, zero duplicates removed, and zero gaps.

## Decisions

- Explicit Polars expressions were selected over another validation framework for a small,
  inspectable schema boundary; see [P04 research](../../docs/research/P04-research.md).
- D-0017 uses checksum lineage rather than timestamps and refuses to backdate calendar release
  values; see [decision log](../../docs/decisions/DECISIONS.md).
- D-0016 prevents encoding or labeling an exact ICE DXY/USDX replica without permission. This is a
  scoped licensing blocker, not a blocker for the remaining Silver outputs.

## Scenario results

| Scenario | Expected | Actual | Result |
|---|---|---|---|
| Out-of-order + duplicate minute | Sort; keep deterministic last row; count duplicate | Exact order and one removal asserted | Pass |
| 30-minute feed outage | Preserve both observations and mark 30 missing minutes | `gap_minutes_before=30` | Pass |
| Flash spike | Keep row and set flag using prior data only | 50% move retained and flagged | Pass |
| DST week | London tag follows local clock | Winter 08:30 UTC and summer 07:30 UTC both tagged | Pass |
| Weekend crypto | Keep row and tag weekend | Saturday BTC row retained | Pass |
| XAUT while XAU unavailable | Null basis, never stale value | Missing exact minute and tagged weekend both null | Pass |
| No-lookahead resampling | Later unfinished value cannot alter completed bar | Unit + Hypothesis property are invariant | Pass |
| Empty / NaN / infinity / negative | Fail closed | Parameterized validation tests raise | Pass |
| Unpaired BID/ASK | Fail closed | Adapter rejects unmatched timestamps | Pass |
| Windows path with spaces | Build and resume | Integration test uses `silver path` | Pass |
| Interrupted/unchanged rerun | Atomic target and checksum skip | Sample rerun skipped 84 + 3 + 7 units | Pass |
| Corrupt derived output | Detect checksum mismatch and rebuild dependency | Damaged 5m Parquet repaired from verified Bronze | Pass |
| Partition-bounded scale | Avoid whole-history materialization | Builder reads and writes one market partition at a time | Pass |

Network retry, 429, partial-download, missing environment, malformed configuration, CRLF, and locked
file scenarios are enforced at the upstream Bronze/config boundary and remain covered by the P00–P03
tests. P04 makes no network request and reads no environment secrets.

## Known limitations

- Full six-year Silver output waits for the P02 storage blocker; the verified seven-day sample is
  complete for all current market datasets.
- Exact DXY/USDX is absent under D-0016. No substitute is mislabeled as the protected index.
- The XAUT/XAU basis assumes nominal USDT/USD parity and records that assumption in every row.
- Calendar actual/forecast/previous values are excluded from Silver until a trustworthy observed-at
  contract exists.
