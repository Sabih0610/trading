## Summary

The project is an installable `src/tb` application with exact direct dependency pins and a cross-platform uv lockfile. Configuration is optional and typed; blank or missing keys disable integrations. Logs are JSON on disk, readable on the console, and redact known/configuration-shaped secrets. Time helpers reject naive datetimes and convert London/New York sessions through IANA time zones. `tb doctor` reports local state without network access.

The supplied skill installer was audited. Five skills were retained behind the project safety overlay; the production-write P2P skill and executable short-selling backtester were quarantined and removed from future installer runs.

## Known limitations

- Ollama shows configured when `OLLAMA_HOST` is present; doctor does not probe whether the local service is running because it must remain a fast offline diagnostic.
- WinGet supplied uv 0.13.3 while upstream 0.13.4 existed. No P00 behavior depends on the patch difference; exact Python dependencies are locked.
- The upstream Binance skill repository no longer exposes the requested spot-specific folders, so no Binance skill was substituted. Later exchange code must use official documentation and the project safety rules.
- Empty data layer directories are local and git-ignored; setup recreates them on every workstation.
