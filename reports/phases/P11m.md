## Policy and accounting

`MAX_HOLDING_DAYS=10` is compiled. The strict integer config defaults10 and rejects0,11,fractional,float,bool/string values. Global EOD accepts actual booleans only (StrictBool), defaultsFalse; existing proposals defaultTrue, and effective EOD is global OR proposal. A proposal cannot exceed the human-configured maximum; optional old bar-count exits can close earlier. Deadlines use actual fill timestamps and the first observed valid event at/after the bound, never a count of available bars.

Daily equity uses net-liquidation values including costs. `SafetyState.last_equity` persists the prior valid mark across restart/UTC rollover, so the first new-day adverse gap counts against that day's2% loss ceiling. The5% peak circuit stays latched. A legacy state without a recorded mark retains its existing anchor conservatively instead of resetting to a gap. Backtest daily realized accounting is measured against the current daily net-equity anchor, rather than charging an earlier day's loss again.

0.5% planned risk,2% daily loss,5% peak drawdown,1x exposure, one position, three trades/day/asset, existing1%/3% hard ceilings and XAUT weekend-entry refusal remain. No external order code or provider activation is added. The dashboard's risk table includes `Max_holding_days` beside `End_of_day_flat`.

- Explicit unique observation ID, prior digest and actual observed_at/known_at available by the current event.
- Every instrument/account/currency/unit/cost/session/source fact unchanged; monotone observation/availability clocks and original24h freshness still required.
- Effective overrides, known_at and seen IDs persisted atomically in the existing append-only event/checkpoint chain; previous quotes removed until a subsequent valid quote.
- Exact duplicates deduplicate; stale/future/wrong-fact/wrong-chain/reused-ID observations refuse. Existing package/risk/code/schema pins and replay reconciliation remain; changed old stores refuse rather than silently reset.

This is fixture software capability only. It does not renew rights/retention or add any genuine provider refresh, operational paper, Testnet or order path. Missing fresh metadata still fails closed; no execution price is invented at a holding deadline.
