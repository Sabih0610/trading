## Implementation and safeguards

New `src/tb/ingest/twelve_data/` contains settings, budget/client, adapter, reference schemas and
finite runner. Existing httpx0.28.1 is reused; pyproject/lockfile unchanged. GET only, fixed
`https://api.twelvedata.com`, exact api_usage/exchange_rate/M1 time_series shapes, two symbols.
No arbitrary method, host or parameters, redirects or inherited proxy. `/price` is unsuitable
for time qualification; `/quote` is unnecessary and does not establish executable broker sides.

TWELVE_DATA_API_KEY is an optional SecretStr in the ignored root environment file, with ACL
restricted to the current Windows account. Auth uses a header; no credentials in URLs/reports.
Unknown errors are sanitized, credential echoes refused. Fixture transports remain synthetic.
All APIs remain optional; missing key exits with a clear disabled message and no network.

Minute/day reservations, actual usage, same-account cache and cooldowns persist in SQLite.
Attempts reserve before sending; ambiguous failures are charged. Remaining-credit headers can
only reduce budget. 429 respects numeric/HTTP-date Retry-After and UTC daily reset, stops requests
and never upgrades. Cache reads keep original receipt time. No inline retry or endless loop.

ReadOnlyMarketFeed's quote/quotes/contract methods explicitly refuse unavailable executable facts.
Reference observations cannot carry fabricated bid/ask, spread, volume or broker clock stamp.
Source-specific M1 Silver permits missing volume; existing MT5/OANDA rules and legacy record IDs
are preserved. Forming candles have separate watermarks, so they cannot suppress a later valid
completion. Unchecked model copies are revalidated before new reference commits.

The runner reuses FeedStore, classifier, OS lease, manifests/checksums, atomic exports and restart
integrity. Coverage restarts per invocation while dedup/session identity persists; downtime never
becomes prospective observation. No scheduler, strategy/account writer, EA or MCP tool was added.

Dashboard shows provider, instrument, UTC source/receipt, freshness, counts, incomplete intervals,
usage and recorded qualification separately from account P&L. Basic display rights are unconfirmed:
the last-price field says withheld. No raw market price is rendered. Existing Streamlit needed a
restart to discard its old imported schema; independent reader/schema tests already passed.
After restarting, the genuine provider view was checked in the browser and rendered both
instruments with price withholding and stopped collection correctly. Status screenshot:
[reference-status.png](../screenshots/P11a.3/reference-status.png). No market prices appear.

## Costs, licensing and recommended P11b step

Two M1 requests/minute need 2880 market credits/day, exceeding 800. Current collection is finite.
A future completed-M5 design querying two symbols every five minutes needs576/day plus checks;
that budget proposal is not implemented capability. Continuous reliability remains unverified.

[Basic pricing](https://twelvedata.com/pricing) says internal non-display; the
[terms](https://twelvedata.com/terms) bind storage/use to tier/documentation and free noncommercial
usage. The bounded private development sample does not establish permanent raw retention, public
display/redistribution, commercial use or model-training rights. No fixed allowable archive
duration was established. Resolve rights before a growing archive/broader use; Git-ignore is not
a license grant. UI prices remain withheld; no market values are published in this report.

After separate P11b authorization, first build a supervised budgeted **reference shadow** consumer
of committed Silver candles with shared causal features, deterministic risk/veto logging and
durable event/restart checks. Do not assign executable fills or P&L. Obtain licensed broker
bid/ask plus contract/session/cost/funded-eligibility evidence before realistic paper accounting.
Keep the existing 2025+ holdout locked and original provider namespaces intact. No P11b code,
24h soak, external order or EA was started in this phase.
