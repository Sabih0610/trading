P05 is in progress. It will produce versioned causal Gold features from Silver, using the same
state machine for batch and streaming evaluation.

## Built

- One `FeatureEngine` computes completed-bar ATR/volatility, EMA trend, confirmed structure,
  sweep/reclaim, ATR-filtered three-bar gaps/fills, order-block proxy, session VWAP/ranges/opens,
  and completed higher-timeframe structure.
- The Polars batch API replays the same engine. State is carried across physical partitions and
  predecessor hashes chain lineage, so a corrected older input invalidates all causal descendants.
- Point-in-time enrichers add known-event proximity, exact-time XAUT/XAU basis z-score, explicit
  unavailable macro fields, historical book nulls, and transparent live Spot book metrics.
- The Gold builder reads only approved Binance spot assets from the registry and writes six
  timeframes under asset/month partitions with feature-version manifests.
- Verified sample: 168 Parquet partitions, 51,940 rows, approximately 8.1 MB; immediate rerun skipped
  all 168 file writes after replaying state.

## Scenario results

| Scenario | Expected | Actual | Result |
|---|---|---|---|
| Batch vs streaming | Exact same schema, null mask, and values | Direct equality passes | Pass |
| Three calendar months | Batch handles continuous 90-day sequence | 2,160 hourly rows pass | Pass |
| Future poisoning | Random later prices cannot change first 60 rows | Hypothesis property passes | Pass |
| First bars | Declared warmups remain null | ATR has exactly 13 initial nulls | Pass |
| Input gap | Reset continuity state | Return/ATR null and `input_gap=true` | Pass |
| Confirmed pivot | Wait for three right bars | Pivot appears only on seventh bar | Pass |
| Sweep/reclaim | Require confirmed level and reclaim | Wick/close scenario emits event | Pass |
| Three-bar gap | Require prior ATR and minimum size | Synthetic displacement emits bounded zone | Pass |
| Event lookahead | Unknown schedule excluded | Event appears only after `known_at` | Pass |
| Stale basis | Never carry old XAU | Missing exact minute stays null | Pass |
| Higher timeframe | Invisible before right edge | Available at `bar_end_utc`, not one minute earlier | Pass |
| Missing macro/book | Null plus explicit availability false | Historical schema verified | Pass |
| Partition boundary | Same state as continuous batch | Two-part replay equals one batch | Pass |
| Resume | Avoid unchanged writes | All 168 outputs skipped | Pass |

## Known limitations

- Exact DXY and live yield changes remain unavailable under D-0016/D-0011; flags are false rather
  than silently substituting another series.
- Historical order books were not ingested, so book features are null. The live calculator requires
  a correctly synchronized Binance Spot local book in P11.
- BOS/CHoCH, sweep, three-bar gap, and order-block names are explicit project approximations, not
  evidence of hidden participant intent.
- Full six-year Gold output awaits the P02 storage constraint; the verified seven-day sample is built.
