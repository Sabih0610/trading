  memory; their object value is cleared after consumption. No token URL, raw response, code, account
  ID or fingerprint is printed, journaled, exported or exposed in the dashboard.
- Read requires private ACLs; a new empty ignored staging file receives owner/SYSTEM ACLs before
  secret bytes. Complete token/expiry/pin replacement flushes/fsyncs and commits atomically with an
  optimistic revision check. Existing unrelated assignments retained. No backup/token JSON or repair.

- Real token transport is fixed TLS host/path, finite 10s timeout/16-KiB body, no redirects/proxy/debug
  URL logging, and sanitized errors. Two private owner flags plus explicit after-approval invocation
