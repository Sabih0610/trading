## Implementation and decisions

- A closed `ForexDatasetPlan` reuses the same documentary owner/reviewer and finite
  retention checks. Written consent is checked for nonempty bytes and SHA-256 only;
  its text is never inspected. Legacy unregistered Dukascopy acquisition refuses.
- HistData preserves exact ZIP and CSV bytes, verifies committed hashes on resume,
  and publishes its Bronze manifest last. The initial constant +5 h specification was corrected in the fix round below;
  side/volume semantics are explicit. Whole-archive admission precedes
  every request. Sequential retries/backoff are bounded.
- Shared yearly publication verifies row counts and canonical content hashes before
  atomically replacing a manifest pointer. Every nonempty symbol/year has one Silver
  file and one per Gold timeframe (1m/5m/15m/1h/4h). Feature state carries across years.
  BID/ASK, mid and spread columns survive every Dukascopy Gold timeframe.
- Weekend close and daily rollover are flagged separately, excluded from missing-open
  coverage penalties. Gaps, duplicates, revisions, spikes and unreliable volume remain
  visible. Data Health opens JSON metadata only, including explicit missing years.
- The required original Vision PDF exceeded the generic text-document cap. A narrow
  bounded PDF exception preserves the existing cap for every other document and retains
  original hash/header/fake-evidence checks.
- The PowerShell medallion wrapper now binds command arguments correctly without a
  Python-path override; two owned Windows launcher tests cover the regression.
